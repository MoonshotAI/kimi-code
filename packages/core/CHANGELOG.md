## 0.2.0

### Minor Changes

- [#5414](https://github.com/MoonshotAI/kimi-code/pull/5414) [`132c4e8`](https://github.com/MoonshotAI/kimi-code/commit/132c4e88b1d316a7d9a9b2f20df4d59a88061dc7) Thanks [@liruifengv](https://github.com/liruifengv)! - Migrate the existing JSONL storage layer into the core package without changing persistence behavior.

- [#5414](https://github.com/MoonshotAI/kimi-code/pull/5414) [`132c4e8`](https://github.com/MoonshotAI/kimi-code/commit/132c4e88b1d316a7d9a9b2f20df4d59a88061dc7) Thanks [@liruifengv](https://github.com/liruifengv)! - Replace the `loop.drained`/`loop.idle` lifecycle events with an optional `continuation` field on `turn.ended`. When a turn ends, `continuation` reports what follows: `'turn'` when queued, steered, notified, or continued work runs next, `'background'` when no follow-up turn is queued but background tasks are still running, and `'none'` when no work remains.
