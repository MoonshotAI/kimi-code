# Backend Frameworks

This is a parent skill bundle containing sub-skills for various backend and server-side frameworks.

## Sub-skills

- `csharp-developer` — C# with .NET 8+, ASP.NET Core, Blazor
- `django-expert` — Django and Django REST Framework
- `dotnet-core-expert` — .NET 8 minimal APIs, clean architecture, microservices
- `fastapi-expert` — FastAPI with Pydantic V2, async SQLAlchemy
- `java-architect` — Spring Boot 3.x, microservices, reactive programming
- `laravel-specialist` — Laravel 10+, Eloquent, Sanctum, Livewire
- `nestjs-expert` — NestJS modules, controllers, guards, interceptors
- `php-pro` — PHP 8.3+ with Laravel/Symfony, PSR standards
- `rails-expert` — Rails 7+, Active Record, Turbo, Sidekiq
- `salesforce-developer` — Apex, LWC, SOQL, triggers, batch jobs
- `spring-boot-engineer` — Spring Boot 3.x, Spring Security 6, JPA
- `websocket-engineer` — WebSocket/Socket.IO real-time systems
