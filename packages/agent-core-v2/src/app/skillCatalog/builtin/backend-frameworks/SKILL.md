# Backend Frameworks

This is a parent skill bundle containing sub-skills for various backend and server-side frameworks.

## Sub-skills

- `backend-frameworks.csharp-developer` — C# with .NET 8+, ASP.NET Core, Blazor
- `backend-frameworks.django-expert` — Django and Django REST Framework
- `backend-frameworks.dotnet-core-expert` — .NET 8 minimal APIs, clean architecture, microservices
- `backend-frameworks.fastapi-expert` — FastAPI with Pydantic V2, async SQLAlchemy
- `backend-frameworks.java-architect` — Spring Boot 3.x, microservices, reactive programming
- `backend-frameworks.laravel-specialist` — Laravel 10+, Eloquent, Sanctum, Livewire
- `backend-frameworks.nestjs-expert` — NestJS modules, controllers, guards, interceptors
- `backend-frameworks.php-pro` — PHP 8.3+ with Laravel/Symfony, PSR standards
- `backend-frameworks.rails-expert` — Rails 7+, Active Record, Turbo, Sidekiq
- `backend-frameworks.salesforce-developer` — Apex, LWC, SOQL, triggers, batch jobs
- `backend-frameworks.spring-boot-engineer` — Spring Boot 3.x, Spring Security 6, JPA
- `backend-frameworks.websocket-engineer` — WebSocket/Socket.IO real-time systems

Load a sub-skill with the `Skill` tool using its dotted name, e.g. `Skill(skill="backend-frameworks.csharp-developer")`.
