Bind verified real HTTP traffic to an already-registered finding. finding_node_id is the finding's exploration-graph node id (the id report_finding returned). All refs in a batch succeed or fail together; duplicate refs do not overwrite existing notes. Binding marks any existing report as pending update; do not re-probe or create duplicate findings just to attach more evidence. Each ref chooses a role — baseline / proof / verification / supporting — and should state in its note how the traffic supports the finding's conclusion. Only a proof or verification body can later make a finding "verified".
