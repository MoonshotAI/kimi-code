Inject a hint into the exploration: a piece of operator context, guidance, or a lead that the planner and workers should take into account. A hint is advisory knowledge, not an executable direction — use `add_intent` to create work.

- `text`: the hint content (what to keep in mind, a credential location, a known weakness, a constraint to respect, etc.).
- `asset_ids` (optional): the asset ids this hint relates to.
