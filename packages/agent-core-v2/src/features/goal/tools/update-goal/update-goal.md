Set the status of the current goal. `active` resumes a paused or blocked goal when the user explicitly asks you to work on it again. `complete` and `blocked` end autonomous work: while a goal is active, the goal reminder at the start of each turn states exactly when each one is warranted — follow it, and do not call this tool merely because you finished a slice of work. After `complete` or `blocked`, write the completion summary or the blocker explanation in your next message.
