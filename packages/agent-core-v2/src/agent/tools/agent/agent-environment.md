Environment binding: by default the subagent inherits your current environment binding and runs its tools on the same environment as you. Pass `environment` with an environment id from the available environments list to bind it elsewhere instead — for example a build host or a throwaway container created with `connect`. The subagent connects to the target eagerly, so an unreachable environment fails the spawn instead of starting a broken agent. Ignored when resuming — resumed agents keep their own binding.
