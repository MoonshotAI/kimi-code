Fetch content from a public `http`/`https` URL. A note at the top of the result says whether you received the page's extracted main text or the full response body verbatim. Other schemes and private or loopback addresses are not fetched, and very large pages may be truncated or refused.

The fetch carries no login or session, so pages behind authentication (private repositories, internal dashboards) return a sign-in page or an error instead of the content. If the result looks like a generic landing or sign-in page, that is the login wall, not the answer; reach the content through a credentialed route such as an authenticated CLI or MCP tool.
