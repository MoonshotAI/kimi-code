Invoke a registered skill from the current skill listing. BLOCKING REQUIREMENT: when a skill from the listing matches the user's request, you MUST call this tool (not free-form text). Do not re-invoke a skill to repeat work already done: if a `<kimi-skill-loaded>` block for it with the same `args` is already present in the conversation, follow those instructions directly instead of calling the tool again. Do call the tool again when you need the skill with different arguments — the loaded block was expanded with the earlier `args` and will not reflect new inputs. To read a resource file bundled with a skill, call this tool with `resource` set to the file's skill-relative path (the loaded block lists the available paths under `<bundled-resources>`): a resource fetch returns the file content directly and does not invoke the skill.
