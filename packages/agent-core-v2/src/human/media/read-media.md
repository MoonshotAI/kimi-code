Read an image or video file and view its content. Relative paths resolve against the working directory. Directories and text files are not supported.

**When to use:**
- The user asks you to look at, analyze, describe, or compare images or videos
- You need to verify visual content produced by an earlier step, such as a screenshot, a generated image, or a recording

**When NOT to use:**
- Text files of any kind, including source code and documents
- Files larger than 100MB
