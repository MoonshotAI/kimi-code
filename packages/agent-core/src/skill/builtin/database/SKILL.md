# Database & Data

This is a parent skill bundle containing sub-skills for databases and data processing.

## Sub-skills

- `database.data-analyst` — SQL, pandas, statistical analysis
- `database.database-optimizer` — PostgreSQL/MySQL query optimization, indexing
- `database.pandas-pro` — pandas DataFrame operations, cleaning, aggregation
- `database.postgres-pro` — PostgreSQL EXPLAIN, JSONB, extensions, VACUUM tuning
- `database.spark-engineer` — Apache Spark DataFrame transformations, Spark SQL
- `database.sql-pro` — SQL query optimization, schema design, performance

Load a sub-skill with the `Skill` tool using its dotted name, e.g. `Skill(skill="database.data-analyst")`.
