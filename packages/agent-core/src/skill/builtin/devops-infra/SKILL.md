# DevOps & Infrastructure

This is a parent skill bundle containing sub-skills for DevOps, infrastructure, and reliability.

## Sub-skills

- `devops-infra.chaos-engineer` — Chaos experiments, failure injection, game days
- `devops-infra.cli-developer` — CLI tools, argument parsing, shell completions
- `devops-infra.cloud-architect` — AWS/Azure/GCP architecture, migration, cost optimization
- `devops-infra.devops-engineer` — Dockerfiles, CI/CD pipelines, Kubernetes manifests, Terraform
- `devops-infra.kubernetes-specialist` — K8s deployments, pod security, network isolation
- `devops-infra.monitoring-expert` — Prometheus/Grafana, logging pipelines, tracing
- `devops-infra.sre-engineer` — SLIs/SLOs, error budgets, incident response, capacity
- `devops-infra.terraform-engineer` — Terraform IaC across AWS/Azure/GCP

Load a sub-skill with the `Skill` tool using its dotted name, e.g. `Skill(skill="devops-infra.chaos-engineer")`.
