# DevOps & Infrastructure

This is a parent skill bundle containing sub-skills for DevOps, infrastructure, and reliability.

- `cli-developer` — CLI tools, argument parsing, shell completions
- `cloud-architect` — AWS/Azure/GCP architecture, migration, cost optimization
- `devops-engineer` — Dockerfiles, CI/CD pipelines, Kubernetes manifests, Terraform
- `kubernetes-specialist` — K8s deployments, pod security, network isolation
- `monitoring-expert` — Prometheus/Grafana, logging pipelines, tracing
- `sre-engineer` — SLIs/SLOs, error budgets, incident response, capacity
- `terraform-engineer` — Terraform IaC across AWS/Azure/GCP
