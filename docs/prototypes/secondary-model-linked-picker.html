子代理模型：模型 + effort 联动选择 — 两种交互

两种形态都只保留一行设置项；选择后原子写入 {model, default_effort}。点开下拉实际操作对比。模型数据为示意（注意各模型 effort 集合不同，K2.7 Coding Highspeed 无 effort 列表）。

方案 A · 单 Select 组合选项 — 复用现有 Select，选项按模型分组、组内列该模型的 effort

改动最小：键盘 / 焦点 / 下拉样式全部现成。缺点：模型多时清单变长（模型 × effort 平铺）；组头即模型名。
