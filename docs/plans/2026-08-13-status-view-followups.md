## 2. 工作区管理增强

工作空间 tab / 主页现在是「目录 + 最近会话」。要丰富成可管理 session：例如在目录行/主页里能看全部会话（含已完成）、批量选择、完成/置顶/移除等管理动作。具体形态待定（目录行展开？主页加「管理」入口？）。

## 3. 一键全部完成

提供「全部完成」：把当前进行中（或筛选范围内）的会话一键全部标记完成。需要考虑：入口位置（进行中 tab 头部？视图菜单？）、是否需要二次确认（现完成链路是免确认 + 撤销 toast，批量撤销要支持批量恢复）、运行中的会话是否跳过。

## 4. 「完成」和「归档」拆成两种状态

当前「完成」复用 archived 字段（换皮）。要拆成双轨：完成（done，成绩册，PR merged 语义）≠ 归档（archive，放弃/收纳语义）。这需要 kimi-code server 侧支持：session 增加独立 done 状态（或 archived 加子类型）、v2 查询按新状态过滤、恢复路径区分。客户端侧已完成 tab 的数据链路（doneSessions 分页、local prepend）已按独立数组设计，切换成本低。届时行 hover/菜单提供两个动作（完成 / 归档），已完成 tab 可按状态再细分。
