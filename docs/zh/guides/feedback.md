# 提交反馈

启动桌面应用或 `kimi web` 前，设置 `KIMI_CODE_EXPERIMENTAL_DESKTOP_FEEDBACK=1` 可开启全局反馈表单和本机回复评价。对于 SSH 会话，能否评价回复、是否可以附带会话记录，由远程主机上的同一开关决定。

登录 Kimi Code 后，可以在侧栏选择「发送反馈」，或在输入框输入 `/feedback`。如果要评价某条回复，可以直接在回复下方点赞或点踩。反馈用于排查问题和改进 Kimi Code。

## 提交时会发送什么

点击赞或踩时，Kimi Code 会记录这次评价、所选回复的会话和轮次标识，以及可用的模型和请求标识。再次点击同一按钮可以撤销。重新打开应用或刷新浏览器后，评价按钮会恢复未选中状态。点踩后填写的原因和补充说明，会在点击「提交」时发送。

全局反馈会发送你选择的类型、填写的描述、反馈入口和客户端信息，例如版本和操作系统。在会话中开始填写的草稿会记住该会话的标识。关闭表单后，草稿保留在当前窗口。如果在另一个会话中勾选「提交当前会话记录」，反馈和附件都会关联到新选的会话。你可以在回执中复制反馈 ID，方便后续沟通。

## 选择要附带的内容

会话记录和诊断日志默认均未勾选。提交前可以逐项选择。

在全局反馈中勾选 SSH 会话记录后，远程主机会临时打包该会话。本机会分段取回归档，并提交给产生这条反馈的服务。传输结束后会删除远端副本。如果连接中断导致删除失败，副本会在 24 小时后过期。

| 选项 | 提交内容 |
| --- | --- |
| 会话记录 | 这次反馈关联会话的消息、工具调用和结果，以及保存在该会话中的附件。这些内容可能包含代码片段和文件路径。 |
| 诊断日志 | 桌面应用的运行日志、应用版本、操作系统和处理器架构。此选项在桌面应用中提供。 |
| 图片和视频 | 你在全局反馈中选择、粘贴或拖入的文件。最多 5 个文件，其中最多 1 个视频。每张图片最多 10 MB，视频最多 100 MB。 |

提交反馈正文后，应用会在后台提交所选附件。如果有附件提交失败，可以在提示中点击「重试提交」，只重新提交失败的附件。
