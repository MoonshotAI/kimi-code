### 新功能

- 新增会话批量管理页面。
- 侧边栏新增「进行中 / 已完成 / 工作空间」标签，可标记任务完成。
- 搜索面板支持搜索工作区，点击结果后侧边栏自动定位。

### 优化

- @ 提及的文件、文件夹和技能显示为图标胶囊，悬停查看详情、点击打开。
- 子 Agent 面板更名为「后台 Agent」。
- 降低动画功耗：页面隐藏或开启「减弱动态效果」时动画自动暂停。
- 更新弹窗的下载进度改为在按钮上实时显示。

### 修复

- 修复后台 Agent 面板多处状态问题：新任务无法取消、状态误显示。
- 修复消息中 YAML frontmatter 被渲染成巨型标题的问题。
- 修复消息中 (c)、-- 等普通文本被渲染成符号的问题。
