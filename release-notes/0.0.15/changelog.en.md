### Features

- You can now drag a folder into the input box.
- The sidebar session list now offers a flat list view.
- Preview any file path mentioned in chat, including files outside the workspace.

### Polish

- A persistent card now stays in the session when a model request fails.
- Retry progress is now shown in the working indicator during automatic retries.
- Pinned sessions and the Workspace header stay fixed when scrolling; pinned area is collapsible.

### Bug Fixes

- Fixed the model picker overflowing the screen when many models are available.
- Fixed code blocks not using a monospace font and appearing too small.
- Fixed attachments being silently dropped when sent with a Skill command.
- Fixed premature pinyin-input submission and text selection issues when renaming sessions or workspaces.
