### 新功能

- 焕新 UI 已经上线：工具调用、思考过程、折叠摘要与提问、审批卡片等改为新样式。
- 新增截图标注功能，输入框左下角+号或 Cmd/Ctrl+Shift+S 唤起。
- 面板标签页支持拖动排序、右键关闭和 Control+Tab 循环切换。

### 优化

- 审批卡片改用 Enter 批准、Esc 拒绝，数字键仍可用。
- 输入框内连按两次 Esc 可中断运行中的会话。
- 优化消息流加载与切换会话的性能，减少等待时间。

### 修复

- 修复中断回复后重发消息未生成新回复、撤销引导消息后聊天内容丢失或重现的问题。
- 修复会话较多时流式输出界面卡顿、滚动不跟手的问题。
- 修复代码差异与 Markdown 内容的多处显示问题。
