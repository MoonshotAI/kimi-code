### Features

- The refreshed UI is live across tool calls, thinking, summaries, and question/approval cards.
- New screenshot annotation: use the + button in the input box or press Cmd/Ctrl+Shift+S.
- Panel tabs now support drag reordering, right-click closing, and Control+Tab cycling.

### Polish

- Approval cards now use Enter to approve and Esc to reject; number keys still work.
- Press Esc twice in the input box to interrupt the running session.
- Faster message loading and session switching, with less waiting.

### Bug Fixes

- Fixed resending after interruption producing no reply, and undoing a steer losing chat content.
- Fixed stuttering and unresponsive scrolling during streaming with many sessions.
- Fixed multiple display issues in diffs and Markdown content.
