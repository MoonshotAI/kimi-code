### Features

- Added sleep prevention under Settings → General.
- Archived sessions can be deleted under Settings → Archived Sessions.
- Added auto-mention for pasted images under Settings → Agent & Sessions → Composer.

### Polish

- Steer messages now show unread, read, and insertion progress indicators.
- Reduced reading-position jumps when scrolling up or loading older messages.
- New sessions can open the file tree and preview workspace files.

### Bug Fixes

- Fixed Swarm mode not working in empty sessions.
- Fixed history cache invalidation during automatic compaction in long conversations.
- Fixed in-app browser crashes, click failures, and zoom rendering issues.
