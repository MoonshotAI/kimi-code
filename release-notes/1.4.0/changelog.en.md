### Features

- Support SSH remote projects that keep running while this machine is offline.
- Install the `use-kimi-code` skill to interact with other agent clients; see [Agent to Agent](https://moonshotai.github.io/kimi-code/en/guides/other-agents.html).

### Polish

- Select and copy regions, rows, or columns in Markdown tables.
- Pin projects and reorder them alongside pinned sessions.
- Mark sessions as unread or read from the context menu.
- Steer running agents immediately by default; restore queueing in Settings.

### Bug Fixes

- Prevent some websites from flagging the built-in browser as insecure.
- Honor system HTTP and HTTPS proxy settings for remote control connections.
- Stop expired credentials from triggering repeated cryptic model-picker errors.
