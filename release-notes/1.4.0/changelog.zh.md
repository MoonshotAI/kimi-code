### 新功能

- 支持 SSH 远程项目，本机离线后任务继续运行。
- 支持安装 `use-kimi-code` 技能，可以跟其他 Agent 客户端交互，详情见 [Agent to Agent](https://moonshotai.github.io/kimi-code/zh/guides/other-agents.html)。

### 优化

- Markdown 表格支持选择区域、行或列并复制。
- 项目可置顶并与置顶会话一起拖拽排序。
- 会话右键菜单新增「标记未读 / 已读」。
- 运行中发消息默认立即 Steer，可在设置中恢复排队。

### 修复

- 修复部分网站将内置浏览器误判为不安全的问题。
- 修复远程控制连接未使用系统 HTTP/HTTPS 代理的问题。
- 修复过期凭证导致模型选择器反复弹出不明错误。
