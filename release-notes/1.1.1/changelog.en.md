### Features

- New workspace trust prompt: untrusted folders ask for confirmation before you can send messages.
- Switching models mid-session now asks to start new, compact, or continue.
- /compact can now be queued while the agent is running, executing when its turn comes.
- New "Reload session" applies external AGENTS.md, skill, and config changes immediately.
- Opening a session already used by another client now shows a confirmation with one-click retry.

### Polish

- File Tree panel can now sit left or right, with a new toggle icon.

### Bug Fixes

- Fixed UI stutter and device heating during streaming in long conversations.
- Fixed message text, attachments, and queued messages being lost after send failures.
- Fixed `kimi app` on Windows failing to open workspaces, and new sessions stuck loading.
