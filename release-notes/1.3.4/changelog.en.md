### Features

- Customize UI, transcript, code, and terminal fonts, or use bundled fonts.
- Fold long pasted text automatically in the composer, and click to view or edit.
- Include files ignored by .gitignore when mentioning files with @.
- Drag terminal tabs to reorder or move them between bottom and right panels.
- Magnify pixels and pick colors while taking screenshots.
- Open local files in the built-in browser, with tabs muted by default.
- Change the primary directory of a project.
- Import Google GenAI providers for custom models.
