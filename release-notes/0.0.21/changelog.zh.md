### 新功能

- 前台运行的 Bash 命令和子代理可转为后台任务，点击卡片「转为后台」即可。
- 图片和视频可直接拖入输入框作为附件发送，悬停预览并显示上传进度。
- 设置 → 高级新增消息自动折叠与工具调用汇总开关。

### 优化

- 右侧边栏改为多标签页，终端与面板开关固定在最右侧。
- 默认思考改为分档选择，新会话遵循设置里的默认档位。
- 撤回编辑现在可撤回到任意一条用户消息。
- 内置 Kimi Code 升级到 0.39.0，修复归档与中断恢复崩溃问题。

### 修复

- 修复反复切换会话或开关右侧面板后内存持续增长的问题。
- 修复切换会话或断线重连后消息重复、丢失或状态未更新的问题。
- 修复侧聊偶发卡死、提前结束或内容重复的问题。
