### Features

- Sessions can now be pinned from the session menu; pinned area height is drag-adjustable.
- Added kimi.com and kimi.ai OAuth sign-in options.

### Polish

- Faster file search in the @ menu, with path-fragment matching and hit highlighting.
- The composer toolbar adapts to narrow windows; the model selector collapses to an icon.
- Subagent cards are now labeled Foreground or Background.
- Sign-in takes effect immediately after authorization, no more polling wait.

### Bug Fixes

- Fixed slow session list loading with many workspaces.
- Fixed workspaces disappearing from the sidebar after archiving the last session.
- Fixed skill activation messages that could not be undone and resent.
