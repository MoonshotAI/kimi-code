### 新功能

- Kimi Code Desktop 1.0.0 发布：桌面上的 AI 编程助手。
- 看得见的 AI 编程：工具调用、思考过程、文件修改全程可见，敏感操作需审批。
- 从对话到交付：计划可评审，长任务可转后台，支持多 Agent 并行协作。
- 内置浏览器：右侧面板浏览网页，页面信息与 Agent 共享，无需切窗口。
- 指哪改哪：截图标注、划词评论、@ 提及文件，网页上也能点选元素。
- 不用离开窗口：内置终端、差异查看、文件预览，文件路径可直接点开。
- 管理你的所有项目：多工作区、多会话并行，支持置顶与全局搜索。
- 账号与生态：kimi.com / kimi.ai 一键登录，套餐用量随时可查。
