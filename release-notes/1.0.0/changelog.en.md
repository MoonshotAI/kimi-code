### Features

- Kimi Code Desktop 1.0.0 is here — an AI coding assistant on your desktop.
- See tool calls, thinking, and file changes as they happen; approvals required for sensitive actions.
- Review plans, run long tasks in the background, and work with multiple agents in parallel.
- Browse the web in the side panel and share page context with the agent.
- Annotate screenshots, comment on selections, @-mention files, and pick elements on web pages.
- Built-in terminal, diff view, and file preview; open mentioned file paths directly.
- Run multiple workspaces and sessions in parallel, with pinning and global search.
- Sign in with kimi.com or kimi.ai and check your plan usage anytime.

### Bug Fixes

- Fixed noticeable UI and input lag during session output.
- Fixed folders incorrectly opening to the Desktop on Windows.
- Fixed several UI glitches, including session-switch flicker, stray address-bar suggestions, and inconsistent shortcut labels.
