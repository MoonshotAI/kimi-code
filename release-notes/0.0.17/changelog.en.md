### Features

- Added a Plugins settings page to install and manage plugins from marketplaces or local sources.
- Session titles can now be generated automatically (experimental).
- Added a plan viewer panel showing the full plan, review results, and feedback.

### Polish

- Plan and Goal are now undoable input markers that take effect on send.
- Workspace panels (Todos, Sub Agent, Background Tasks) are now cards with status filters.
- Slash command and @ menus restyled, with fuzzy search for slash commands.
- Reply timestamps now show message time instead of working duration.

### Bug Fixes

- Fixed forking sessions with very long history always timing out.
- Fixed request timeouts misreported as "cannot connect to the Kimi server".
- Fixed the slash command panel staying visible after switching sessions or losing focus.
