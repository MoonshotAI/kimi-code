### 新功能

- 点击聊天中的本地 HTML 文件，可在右侧内置浏览器按真实网页打开。
- 下载列表支持暂停、继续、取消和重试，并显示下载速度和剩余时间。
- 设置中新增自动生成会话标题开关，关闭后不再用 AI 命名新会话。
- 右键点击会话中的文件名，可以复制路径或在文件夹中显示。
- 在输入框中高亮有效的行首命令，并在未输入参数时显示参数提示。

### 优化

- 聊天中的 Markdown 表格改用圆角外框，加宽后可占满会话整宽。
- 定时任务在对话中显示易读的名称、周期和详情。

### 修复

- 修复恶意网页可通过本地内嵌服务器执行任意命令的安全漏洞。
- 修复长对话打开卡死、流式输出掉帧和移动端内存过高的问题。
- 修复删除会话后确认弹窗一直转圈无法关闭的问题。
- 修复子代理模型设置在界面显示未配置、保存后不生效的问题。
- 修复 Swarm 工具卡片与成员状态显示的一系列问题。
- 修复 Fork 会话继续聊天后标题被自动重新生成覆盖的问题。
- 修复内置终端 Cmd+K 误弹出搜索面板、Ctrl+C 选中文字时无法复制的问题。
