### 新功能

- 支持 AI 自动生成会话标题。
- 支持在会话右键菜单中永久删除会话，删除前会弹窗确认。
- Markdown 预览支持将文档元数据显示为键值卡片和标签列表。

### 优化

- 输入框通过可排序的媒体栏集中预览图片和视频。
- Cmd/Ctrl+W 先返回新建会话页，再按一次关闭窗口。

### 修复

- 修复会话加载、回看和流式输出时的多处卡顿问题。
- 修复新建会话时发送按钮一直置灰无法发送的问题。
- 修复 Ctrl/Cmd+S 会把队列中所有消息合并发送的问题。
- 修复全局搜索仍显示已删除会话的问题。
- 修复新建对话后旧对话被误标为未读并弹出“回合完成”通知的问题。
