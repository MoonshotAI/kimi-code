### 新功能

- 新增应用内浏览器，可在对话旁浏览网页、标注页面，并让 Agent 操作网页。

### 优化

- 模型选择器和设置中的 Kimi 订阅供应商不再显示内部标识。
- 模型选择按钮、子代理模型信息和辅助模型选择器中的思考程度统一为首字母大写。

### 修复

- 修复 macOS 按 Command W 时关闭窗口而非当前右侧面板标签的问题。
- 修复等待回复时不再显示「请求中…」或「思考中…」提示的问题。
- 修复菜单的多处问题，包括顶部区域无法操作和切换会话后误作用于其他会话。
- 修复对话和面板中多处间距、对齐与图标大小不一致的问题。
- 修复键盘聚焦图标按钮时不显示提示的问题。
