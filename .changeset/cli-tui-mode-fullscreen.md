Add a `tui_mode` preference for a fullscreen alternate-screen UI: the transcript becomes a scrollable viewport with mouse wheel scrolling, text selection, a scrollbar, and transcript search (Ctrl-Shift-F), while the editor and chrome stay docked at the bottom. Set `tui_mode = "fullscreen"` in ~/.kimi-code/tui.toml and restart.
