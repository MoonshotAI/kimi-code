## 二、新功能（feat 17 个）

### 2.1 Remote Control：把本机 Web UI 远程暴露（实验）`#3034`

最大的新功能。手机/别的电脑扫二维码或开链接、登录同一 Kimi 账号，即可远程查看任务进度、批准/拒绝权限、继续对话、新建会话——**计算和文件操作全部仍在本地**，网页只是"远程窗口"。实验开关 + 付费会员。

- **架构**：不直连。本地进程只绑回环，通过两条 WebSocket（management + HTTP tunnel）连 Kimi 中转服务 `https://code-rc.kimi.com`，把远端浏览器的 HTTP/WS 请求桥接到本地 web server，途中做请求/响应头过滤重写与本地鉴权。访问链接形如 `code-rc.kimi.com/devices/<设备ID>/`（链接本身不含敏感 token）。单实例锁 `~/.kimi-code/server/rc.json`。
- **入口**：`kimi rc`（别名 `kimi remote`）、`kimi web --remote-control`、TUI 里 `/remote-control`（`/rc`）；开关 `KIMI_CODE_EXPERIMENTAL_REMOTE_CONTROL=1`。启动打印链接 + 终端内联二维码。
- **代码**：`apps/kimi-code/src/cli/sub/web/remote-control.ts`（核心，含 `RemoteControlClient`）、`remote-control-lock.ts`、`remote-control-qr.ts`；文档 `docs/zh|en/guides/remote-control.md`（`#3398`）。
- **配套修复**：`#3283` relay 重部署静默断连（无 close frame）→ 加心跳看门狗（30s ping、300s 无入站即重连），注册失败按瞬态退避重试；`#3331` 启动输出显示完整链接（删掉会截断设备 ID 的短链）；`de0f6b17` rc 输出把字面 `\n` 换成真实换行。
