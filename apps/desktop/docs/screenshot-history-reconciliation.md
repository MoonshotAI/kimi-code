## 后续同步规则

功能源分支向 main 提 PR。dev 的修复从最新 dev 单独建分支，只带必要截图差异；不把 dev 合回功能源分支。构建验收同时记录安装版本与构建提交，不能只检查任务执行成功。

自动检查与人工验收的范围分别见 [显示检查](./screenshot-presentation.md)、[权限恢复](./screenshot-permissions.md)、[贴图](./screenshot-pins.md) 和 [Windows 验收](./screenshot-windows.md)。源码与模拟测试通过不代表 Windows 实机或系统权限弹窗已经通过。
