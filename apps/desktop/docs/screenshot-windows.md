# Windows 截图验收

目标范围是 Windows 10 / 11 x64 的普通桌面截图。屏幕捕获沿用 Electron `desktopCapturer`，标注、评论与输出共用编辑器，不单独维护 Windows 截图引擎。下面的 Windows 原生检查与人工验收必须在 Windows 执行，不能以 macOS 单测通过代替。

## 构建与自动检查

安装 Visual Studio 2022 或更新版本的 C++ x64 工具与 Windows SDK。`pnpm --filter kimi-code-app run build:native:screenshot` 使用 `vswhere` 查找编译器并加载 `vcvars64.bat`，不要求先手动打开开发者命令行。打包时只包含运行产物，不包含 `.obj`。

PR 与 main 的 Windows CI 会编译辅助程序，再运行：

```sh
pnpm --filter kimi-code-app exec electron tests/main/fixtures/screenshot-windows-native.cjs
```

该检查创建真实 Electron 普通窗口、所属对话框、不显示任务栏按钮的浮动窗口、隐藏窗口、最小化窗口及模拟截图浮层，调用真实辅助程序，验证窗口保留与排除，并验证输出坐标格式。随后运行截图相关单测；手动触发 CI 时运行全量单测。混合缩放和负坐标的单测在各平台都执行，但屏幕接口使用模拟数据。

窗口检测只传入需要排除的浮层句柄，调用时隐藏控制台。辅助程序超时或失败记录主进程日志，手动框选仍可使用。窗口的物理坐标按每块显示器分别换算，保留窗口原顺序，不单独提取窗口图像。

## 体验包

按 [Preview 构建说明](./preview-build.md) 对已推送分支开启 `preview` 构建，下载 Windows EXE。Preview 与正式版分开安装、分开 Electron 配置和任务栏身份，不注册正式版深链或自动更新；登录、会话与工作区仍共享，不能作为数据沙箱。

## 必须完成的人工验收

以下项目需要逐项记录实机验收；已完成的自动验证见文末，不能替代全部人工走查。记录系统版本、屏幕布局与缩放比例、Preview 版本，以及复现步骤。

- [ ] 退出应用后重新打开，首次快捷键和点击入口都能唤起；连续截图至少 10 次，第一次框选不消失。
- [ ] 准备阶段与浮层出现后都能一次 Esc 退出；输入法组字的 Esc 不误退出。
- [ ] 进入、退出没有黑框或缩放闪动；取消后焦点回到正常应用，没有残留浮层。
- [ ] 普通应用、Kimi 自己的窗口、所属对话框可预选；桌面空白不被系统全屏窗口抢占，最小化窗口不参与预选。
- [ ] 两个窗口重叠时，预选框内不额外遮暗前景窗口，导出与屏幕叠放一致；预选后直接拖动框选不闪。
- [ ] 单屏分别检查 100%、125%、150%、200%；双屏检查不同缩放比例、副屏位于左侧或上方，以及窗口跨屏。
- [ ] 主屏和副屏分别框选，尺寸标签、控制点、标注位置与导出范围一致，其他屏幕不默认加遮罩。
- [ ] 箭头、文字、标号、马赛克、撤销、重做、清空均正常；评论和文字输入框的 Ctrl+A/C/V/Z 不被截图接管。
- [ ] 普通 Enter 添加到对话并复制同一张图片，按钮显示 ↵；默认可见的单行评论框按 Enter 同样提交，输入法确认候选字时不提交，Ctrl/Shift/Alt+Enter 不提交。评论不写入剪贴板；保存 PNG 正常。
- [ ] 贴图拖动、边缘与角点等比缩放、滚轮缩放正常；点击 X、双击图片与右键关闭不切换到主应用，原应用保持前台。
- [ ] 快捷键冲突时保留旧绑定并提示，工具提示显示 Ctrl 而不是 Command。
- [ ] 正常截图不出现屏幕录制授权或重启提示；捕获失败、没有可用画面时保留恢复窗口，可重新检查或关闭，说明普通桌面与受保护内容的限制，并提示 Win + Shift + S 后粘贴。具体错误只记入日志，不显示技术错误详情。
- [ ] 重新检查用真实屏幕画面验证，不使用 macOS 权限状态；成功后显示“继续截图”，点击后先关闭引导再开始捕获。没有系统设置、Finder 或重启按钮。
- [ ] 失败引导停留超过一分钟不超时；重试成功进入原截图流程，取消或 Esc 退出，不再叠加通用错误提示；引导关闭后再次截图正常。
- [ ] 与正式版同时安装时，Preview 图标、任务栏分组、配置和重新启动入口独立；两版同时运行造成的全局快捷键冲突有提示。

本轮不承诺 UAC 安全桌面、受保护视频、独占全屏游戏、HDR 精确色彩、远程桌面或 Windows ARM64。若普通桌面验收出现必须更换捕获引擎才能解决的黑屏或严重闪烁，暂停扩大 Windows 支持范围，先重新评估。
