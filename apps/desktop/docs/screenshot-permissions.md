# 截图权限与失败恢复

截图请求在授权过程中保持等待，不丢失原目标对话。引导使用主窗口中的同一个 `app-ui Dialog size=sm`，不连弹原生警告、不叠加通用失败通知。首屏只显示操作说明与一个主按钮，不显示用途短句或技术错误详情；设置路径、Finder 定位和重启集中到“遇到问题”，点击后在同一弹窗切换帮助页。右上角关闭和 Esc 都取消本次截图。

## macOS

| 进入条件 | 显示与操作 |
| --- | --- |
| 首次使用，权限未决定 | 显示需要授权的应用；点击“开启权限”才请求真实屏幕访问，手动设置入口在帮助页 |
| 权限未开启 | 应用名称直接写进说明；主按钮为“打开系统设置”，打开后变为“检查权限” |
| 状态报告已授权，但原生返回拒绝 | 仍进入权限引导；以 ScreenCaptureKit 的真实拒绝结果为准 |
| 系统策略限制 | 提示联系设备管理员，只提供关闭；不诱导反复授权或重启 |
| 非权限捕获错误 | 明确无法读取屏幕，不武断归因；保留恢复操作，不展示技术错误详情 |

设置步骤为：系统设置 → 隐私与安全性 → 屏幕与系统音频录制（旧版“屏幕录制”）→ 开启当前应用 → 返回检查。

正式版、Preview 和 Canary 使用安装包可执行文件的产品名称，不使用 `app.getName()` 可能返回的内部包名。帮助页提供“在 Finder 中显示应用”，再通过设置列表的“＋”添加正确的应用；不模拟系统开关，也不假设任意系统版本都支持拖放添加。[Apple 的添加应用说明](https://support.apple.com/en-ie/guide/mac-help/mchld6aa7d23/mac)

打开设置前保留引导，之后不抢回设置窗口焦点。返回主窗口时检查一次；也可以手动检查。检查使用实际屏幕捕获路径，临时画面只用于判断能否访问，不展示、不保存、不复制。已有权限的正常截图不增加检查开销。

成功后只显示成功说明与“继续截图”。用户点击后，先移除引导并等待页面绘制，再重新捕获当前屏幕，不使用授权检查时的旧画面。检查失败留在同一个窗口；已有开关仍不生效时，可打开帮助页。重启必须二次确认，并明确会中断任务、终端及本次截图；不自动重启、不自动清除系统权限。

原生模块将 `SCStreamErrorUserDeclined` 映射为 `screen-capture-permission-denied`，并保留原系统错误域与编号。不能只记录 `Error.name`，也不能仅凭 Electron 的权限状态认定捕获可用。[Apple 拒绝授权错误定义](https://developer.apple.com/documentation/screencapturekit/scstreamerror/code/userdeclined)

## Windows 与 Linux

直接尝试捕获。失败或无有效画面时，保留恢复窗口和重新检查按钮，不显示技术错误详情、macOS 设置或重启操作。Windows 说明普通桌面、安全桌面、受保护内容和设备策略的区别，提供 Win + Shift + S 后粘贴的替代操作。Linux 提示检查系统屏幕共享请求或使用系统截图工具。

## 取消与并发

- 引导期间暂停原截图超时并释放临时全局 Esc，Esc 由引导处理；输入法组字不触发取消。
- 重新检查最多等待 15 秒，期间不启动重复检查。取消立即结束原请求；迟到结果不能重开引导或截图。
- 同一次请求只存在一个引导。重复触发截图只聚焦现有引导。
- 引导操作只接受主窗口发送、当前截图令牌匹配的请求。旧请求和截图浮层不能触发系统设置或重启。
- 窗口关闭、取消及应用退出都清理监听，不让下一次截图继承旧状态。

## 手动验收

- [ ] 首次安装：取消系统授权后仍有明确步骤，再开启后能继续原截图。
- [ ] 已拒绝：只出现一个引导，打开设置后焦点停留在设置；返回会检查。
- [ ] 曾授权后撤销：即使权限状态缓存仍为 granted，真实拒绝也进入权限引导。
- [ ] 设置已开启但当前进程未生效：不显示虚假成功，允许再次检查或确认后重启。
- [ ] 正式版和 Preview 同时安装：名称和 Finder 定位指向当前应用。
- [ ] 检查超时、取消、首次 Esc、输入法组字、连续触发均不挂起；取消不弹通用失败提示。
- [ ] 检查成功后继续截图，画面不包含引导窗口；添加到原对话仍同时复制图片。
- [ ] Windows 普通桌面恢复成功；无画面和异常能看到恢复指引，不出现 macOS 的设置路径或技术错误详情。

自动化覆盖主进程拒绝与恢复分支、真实捕获探测的调用、取消与迟到结果、IPC 来源、renderer 操作及桥接订阅。系统授权弹窗和设备策略仍需在实际安装包与 Windows 设备上手动验收，不通过修改本机权限数据库来替代。
