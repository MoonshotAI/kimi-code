# Punctuation Rules

## 1. Period Usage (Both Languages)

Omit the final period in **all short UI copy** — even when the text contains two sentences. Periods only separate sentences internally.

**Long explanatory paragraphs** (>15 words) keep full punctuation, including the final period.

| Omit | Examples |
|------|----------|
| Button labels | `保存` / `Save` |
| Titles / headings | `设置` / `Settings` |
| Menu items | `新建会话` / `New chat` |
| List items | `暂无收藏` / `No favorites yet` |
| Empty states | `未连接到网络` / `No internet connection` |
| Toast messages | `已保存` / `Saved` |
| Hover text / tooltips | — |
| Placeholders | `输入邮箱` / `Enter email` |
| Dialog body (single sentence) | `此会话将被删除` / `This chat will be deleted` |
| Error messages (single sentence) | `密码长度必须至少为 8 个字符` / `Password must be at least 8 characters` |
| Multi-sentence short copy | `文件已保存。你可以在库中查看` / `File saved. You can view it in your library` |
| Error + retry (two sentences) | `上传失败，请重试` / `Upload failed. Please try again` |

| Keep Final Period | Examples |
|-------------------|----------|
| Long explanatory paragraph (>15 words) | FAQ answers, help center body text, legal copy |

Note: A CN "cause，action" pair joined by a full-width comma counts as one sentence (no 。 at all); its EN equivalent is usually two sentences joined by an internal period: `上传失败，请重试` / `Upload failed. Please try again`

## 2. Chinese vs English Symbols

- **Chinese sentences**: Use full-width punctuation (， 。 ：), even when English words appear inside.
- **English sentences**: Use half-width punctuation (. , :).

## 3. Ellipsis

- **Chinese**: Use "…" (half of a full-width ellipsis)
- **English**: Use "…" (three half-width dots)
- **Rule**: Use ellipsis **only** for ongoing / loading states. Avoid in all other contexts.

| ✅ Correct (loading state) | ❌ Incorrect (other contexts) |
|---------------------------|------------------------------|
| 正在搜索… | 有问题随时问我… |
| Loading… | 正在搜索中… |
| 文件解析中… | 更多选项… |

## 4. Em Dash

- **Chinese**: Use "—" (half of a full-width em dash)
- **English**: Use "—" (half-width em dash)

## 5. Decorative Characters

Do NOT use `-` or `=` to manually draw horizontal lines.

## 6. Spacing & Punctuation Interaction

- **Inside Chinese text**: Never insert spaces between Chinese characters or between Chinese characters and Chinese punctuation.
- **English text**: Add half-width spaces between English words as per English convention.
- **Mixed CJK + English/Numbers**: Add one half-width space between Chinese and English/numbers.
- **Mixed CJK/English + Numbers**: Add one half-width space between Chinese/English and numbers.

| ✅ Correct | ❌ Incorrect |
|-----------|-------------|
| 正在下载图片 | 正 在 下 载 图 片 |
| Creating your presentation, closing this page will result in the loss of unsaved content | Creatingyourpresentation |
| 正在制作 PPT 中，关闭页面将无法保存已生成内容 | 正在制作PPT中，关闭页面将无法保存已生成内容 |
| 删除 2 个会话 | 删除2个会话 |
