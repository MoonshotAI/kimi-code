# Style Guide

## 1. Capitalization (English)

Use **Sentence case** only: capitalize first word, lowercase rest.

Applies to: titles, buttons, menus, dialog text.

**Exceptions**:
1. Branded product and feature names keep their official capitalization (e.g. Kimi+, Deep Research, Saved Prompts). What counts as branded: **the EN column's exact capitalization in `terminology.md` is canonical** — rows whose Notes say sentence case / 小写 (e.g. Scheduled tasks, Agent priority queue) go lowercase in generic contexts; everything else keeps its table form, in running text too: `Delete this Saved Prompt`.
2. `App` keeps its capital A as a standard shortened form: `Open App`, `Desktop App`, `Mobile App`.

Generic labels are never Title Case: `Membership benefits`, `Flagship model`.

| ✅ Correct | ❌ Incorrect |
|-----------|-------------|
| New chat | New Chat |
| Chat history | Chat History |
| About us | About Us |

## 2. Spacing (CJK — 盘古之白)

Add one half-width space between Chinese characters and English words or numbers.

| ✅ Correct | ❌ Incorrect |
|-----------|-------------|
| 欢迎使用 OK Computer | 欢迎使用OK Computer |
| 剩余额度 2 GB | 剩余额度2GB |

Exception: No space needed if separated by line breaks.

See `punctuation.md` for detailed punctuation and spacing interaction rules.
See `numbers-and-units.md` for number, time, and currency formatting.
