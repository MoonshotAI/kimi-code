# Sentence Patterns

## 1. Six Hard Rules (Both Languages)

1. **Use declarative sentences** for empty states.
   - ✅ 暂无收藏 / No favorites yet

2. **Use imperative sentences** for guidance.
   - ✅ 请稍候 / Enter a valid email address

3. **Never use exclamatory sentences or exclamation marks** (`!` / `！`).
   - ❌ 记忆数量要到达上限了！
   - ❌ Memory limit reached!
   - ✅ 记忆数量即将达到上限 / Memory limit almost reached

4. **Never use double negatives** in either language.
   - ❌ 不是一定要填写
   - ❌ Don't not save
   - ✅ 选填 / Optional

5. **Use direct verb-object phrases for confirmations. No question marks in dialogs.**
   - ❌ 是否删除此消息？ / Are you sure you want to delete this message?
   - ❌ Do you want to delete this chat?
   - ✅ 删除此消息 / Delete this message
   - ✅ 删除此会话 / Delete chat

6. **Never use affirmative wording to guide negative actions**.
   - ❌ 确定删除此消息？ / Confirm delete this message?
   - ✅ 删除此消息 / Delete this message

## 2. Dialog / Popup Rules (Both Languages)

### Description Text

Format: **Verb-object phrase. No question mark, no period.**

| Chinese | English |
|---------|---------|
| 删除 1 条消息 | Delete 1 message |
| 退出此次编辑 | Exit this edit |
| 修改昵称 | Edit nickname |

### Button Actions

| Position | Role | Wording Rule | Chinese Examples | English Examples |
|----------|------|--------------|------------------|------------------|
| Right | Recommended action | Reuse the **verb** from the title | 删除 / 退出 / 更改 / 注销账号 | Delete / Exit / Change / Deactivate |
| Left | Non-recommended action | Usually "取消" or action-specific | 取消 / 继续使用 | Cancel / Keep using |
