# English Abbreviation Rules

Use contractions to maintain a friendly tone.

| ✅ Friendly | ❌ Formal |
|-----------|----------|
| You're | You are |
| We'll | We will |
| Can't | Cannot |
| Didn't | Did not |
| It's | It is |
| Don't | Do not |
| Won't | Will not |

Prefer contractions in informal UI copy (buttons, labels, toasts, dialog text).
In very formal contexts or legal statements, full forms are acceptable.
