# Phrasing Rules

## 1. Action Words (指令/操作)

Do NOT use variant or incorrect forms.

| Use | Never Use | Example |
|-----|-----------|---------|
| 登录 | 登陆 | 退出登录 |
| 注销 | 删除 (for account cancellation) | 注销账号 |
| 退出 | 登出 | 退出登录 |
| 请稍候 | 请稍后 | 暂未连接到网络，请稍候再试 |
| 添加 / 新建 / 上传 | 增加 | 新建会话 |
| 搜索 | 查找 | 搜索历史 |
| 查看 | 查阅 | 查看更多 |
| 确定 | 确认 | — |
| 删除 | 移除 / 清除 | 删除会话 |
| 发布 | 发表 | 发布动态 |
| 编辑 | — | 编辑个人资料 |
| 清空 | — | 清空缓存 |
| 我知道了 | 知道了 | — |

## 2. Top Bar Navigation Patterns

### Page Transition

| Task Type | Transition | Left Action | Right Action |
|-----------|-----------|-------------|--------------|
| In-flow task | Push from right | 返回 / icon < | (empty) |
| New task | Modal from bottom | 关闭 / icon ❎ | 完成 / 发送 / 发布 / 下一步 |

Right action variants:
- **完成**: Save or submit content and close modal
- **发送**: Send to chat and close modal
- **发布**: Only for sharing to moments
- **下一步**: Step jump, not final step

### Top Bar Titles

| Title Type | When to Use | Example |
|------------|-------------|---------|
| Verb-object phrase | Operation-focused screens | 编辑资料 / 选择性别 |
| Noun phrase | Information-focused screens | 记忆空间 |
